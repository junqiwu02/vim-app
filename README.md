# Vimtype

A static, local-first Vim speed trainer. Transform a starting document into the target using real Vim controls, race the clock, and build muscle memory through focused practice.

## Run locally

```bash
npm install
npm run dev
```

Use `npm test` for core engine tests and `npm run build` for a production build.

Runs and imported scenarios are stored in IndexedDB. Preferences use localStorage. No data leaves the browser.
